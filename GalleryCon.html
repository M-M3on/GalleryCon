    How GalleryCon works

    Your image folders become a gallery you can filter, save and share.

    1. 1
      Import a folder

      Menu → Add or Replace. Each folder with images becomes a card; its parent folders become categories.

    2. 2
      Add specifications

      An optional specifications.json in a folder adds technical data: dimensions, countries, links.

    3. 3
      Browse

      Filter by category, search by name or by specification. Click an image to enlarge it.

    4. 4
      Edit

      Menu → Edit mode. Tick cards to delete them or change their category. In the image viewer, add or delete images and edit the specifications. Type a text in the bottom banner (and pick its color) to show it on every page; leave it empty to remove it.

    5. 5
      Save

      Menu → Save changes. Download the listed files and copy them into the data folder.

    6. 6
      Share

      Share the whole GalleryCon folder, or export one standalone HTML file (best under 50 MB).

    Writing a specifications.json

    Optional. Put it in a folder, next to its images. Every field is optional.

    {
  "alternateDesignations": ["AMX-56"],
  "origin": ["France (FRA)"],
  "proliferation": ["France", "United Arab Emirates", "Jordan"],
  "dimensions": [
    { "name": "Length", "value": "9.87", "units": "m" },
    { "name": "Width", "value": "3.71", "units": "m" },
    { "name": "Weight, Combat", "value": "56.5", "units": "t" }
  ],
  "odinUrl": "https://…"
}
    • origin and proliferation: countries for the filters.
    • dimensions: one line per value, with name, value and units.
    • Values are text: "9.87", "25 cm". "INA" or ranges are shown but not searchable.
    • Lengths need a unit (mm, cm, m, km, in, ft, yd) to be searchable.
    • Edited by hand? Use Replace with a folder: Add keeps the specifications already in the gallery.

    Save changes

    Download these files, then copy them into the data folder next to GalleryCon.html, replacing the old ones.

    Nothing to save: the data folder is up to date.

    Files to delete from the data folder

      All files are downloaded. Copy them into the data folder to finish saving.

      • Only the modified files are listed.
      • If the browser renames a file (gc_images-01 (1).js), give it back its exact name.
      • The browser may ask permission to download several files: accept it.
