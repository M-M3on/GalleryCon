    How GalleryCon works

    Your image folders become a gallery you can filter, save and share.

    1. 1
      Import a folder

      Menu → Add or Replace. Each folder with images becomes a card; its parent folders become categories. When adding, a folder already in the gallery (same categories and same name) is merged only if you choose so.

    2. 2
      Add specifications

      An optional specifications.json in a folder adds technical data: dimensions, countries, links.

    3. 3
      Browse

      Use the bar at the top: search, then Categories and Specifications to filter (a click outside closes them). Active filters show as chips: click one to remove it. Click an image to enlarge it.

    4. 4
      Edit

      Menu → Edit mode. Tick cards to delete them, rename them or change their category. In the image viewer, add or delete images, rename the folder and edit the specifications (with your own groups of name / value lines). Type a text in the bottom banner (and pick its color) to show it on every page; leave it empty to remove it.

    5. 5
      Save

      Menu → Save changes. Download the listed files and copy them into the data folder. Menu → Settings gathers the display at opening, the specification criteria shown at opening, the bottom banner and the data file sizes: Save settings downloads gc_config.js.

    6. 6
      Share

      Share the whole GalleryCon folder, or export one standalone HTML file (best under 50 MB).

    Writing a specifications.json

    Optional. Put it in a folder, next to its images. Every field is optional.

    {
  "alternateDesignations": ["AMX-56"],
  "origin": ["France (FRA)"],
  "proliferation": ["France", "United Arab Emirates", "Jordan"],
  "dimensions": [
    { "name": "Length", "value": "9.87", "units": "m" },
    { "name": "Width", "value": "3.71", "units": "m" },
    { "name": "Weight, Combat", "value": "56.5", "units": "t" }
  ],
  "odinUrl": "https://…",
  "Armament": [
    { "name": "Main gun", "value": "120", "units": "mm" }
  ]
}
    • origin and proliferation: countries for the filters.
    • dimensions: one line per value, with name, value and units.
    • Any other key with such lines (Armament) is a custom group, also created in edit mode with “+ Custom group”.
    • Values are text: "9.87", "25 cm". "INA" or ranges are shown but not searchable.
    • Lengths need a unit (mm, cm, m, km, in, ft, yd) to be searchable.
    • Edited by hand? Use Replace with a folder: Add keeps the specifications already in the gallery.

    Files to delete from the data folder

      All files are downloaded. Copy them into the data folder to finish saving.

      • Only the modified files are listed.
      • If the browser renames a file (gc_images-01 (1).js), give it back its exact name.
      • The browser may ask permission to download several files: accept it.

      Change category

      Pick an existing category or type a new one. Separate the levels with “/”.

      Rename the folder

      Only the name shown in the gallery changes: your source folder is not modified.

      Folders already in the gallery

        A merged folder receives the images it does not have yet (same file name = same image) and keeps its own specifications. A folder that is not merged stays unchanged: its images are not imported.

        Settings

        Saved in gc_config.js: copy the downloaded file into the data folder next to GalleryCon.html. Without it, the default settings apply.
